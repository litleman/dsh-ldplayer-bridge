# 测试与验收清单

## A. 安装与页面注入

- [ ] Via 中安装脚本成功。
- [ ] 脚本管理器中显示启用。
- [ ] 打开 chatgpt.com 后出现桥接状态面板。
- [ ] 非 ChatGPT 网站不出现桥接面板。
- [ ] Via 重启后脚本仍然存在并启用。

## B. 本机网络

- [ ] Windows Bridge 监听 127.0.0.1:18765。
- [ ] `adb devices -l` 能看到目标实例。
- [ ] `adb -s <serial> reverse tcp:18765 tcp:18765` 成功。
- [ ] `adb -s <serial> reverse --list` 能看到映射。
- [ ] Via 面板“检查连接”显示在线。
- [ ] 错误 token 时 Bridge 返回 401/403，Via 显示鉴权失败。

## C. 网页交互

- [ ] Bridge 下发简单文本任务。
- [ ] Via 能定位输入框。
- [ ] 输入框出现完整文本。
- [ ] 消息成功提交。
- [ ] GPT 开始生成。
- [ ] GPT 生成完成后脚本提取完整回复。
- [ ] Bridge 收到同一 task_id 的结果。
- [ ] 中文、英文、换行和常见标点传输正确。

## D. 失败场景

- [ ] ChatGPT 未登录时返回明确错误/超时。
- [ ] 页面加载中时不误报成功。
- [ ] GPT 回复较慢时不提前返回。
- [ ] GPT 回复超时后返回错误。
- [ ] Bridge 关闭时 Via 显示离线。
- [ ] ADB reverse 删除后 Via 显示连接失败。
- [ ] 重复任务 ID 不会重复执行。
- [ ] GPT 生成中手动停止时不会误报完整成功。

## E. 端到端最终验收

由 DSH 调用工具发送：
`请只回复固定字符串：DSH_VIA_E2E_OK`

通过条件：
1. DSH 创建任务；
2. Via 脚本领取任务；
3. ChatGPT 页面发送消息；
4. 页面显示 GPT 回复；
5. Via 脚本回传回复；
6. DSH 收到 `DSH_VIA_E2E_OK`；
7. request_id/task_id 完全对应。
