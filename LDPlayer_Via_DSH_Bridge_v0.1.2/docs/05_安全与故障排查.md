# 安全与故障排查

## 安全基线

- Bridge 仅监听 `127.0.0.1`。
- 使用高熵随机 token，并同时配置 Windows Bridge 与 Via 脚本。
- 不从浏览器提取 Cookie、密码或会话 token。
- 不在日志、截图或公开仓库中泄露 token。
- 只在 ChatGPT 域名启用用户脚本。
- 不尝试绕过验证码、登录校验、风控或付费访问限制。
- ADB reverse 仅映射所需端口；不用时可执行 `adb -s <serial> reverse --remove tcp:18765`。

## 常见问题

### 面板不出现
检查 Via 脚本是否启用、`@match` 是否匹配当前地址、JavaScript 是否被站点设置关闭。确认访问的是 `https://chatgpt.com/` 或 `https://chat.openai.com/`。

### 面板出现但离线
依次检查：
1. Windows Bridge 是否运行；
2. Bridge 是否监听 127.0.0.1:18765；
3. ADB serial 是否正确；
4. `adb reverse` 是否成功；
5. token 是否一致；
6. Via 是否支持并授权 `GM_xmlhttpRequest`。

### 提示 GM_xmlhttpRequest 不存在
确认脚本头部有 `@grant GM_xmlhttpRequest`，脚本管理器没有禁用授权 API。检查 Via 版本；Via 源码帮助中列出了该 API，但不同发行版/版本仍需实测。

### 找不到输入框
ChatGPT 前端可能更新。检查页面是否完全加载、是否处于登录后的对话界面。开发者应更新脚本 `findComposer()` 选择器。

### 消息已填入但没有发送
检查 `findSendButton()`；可调整发送按钮选择器。脚本的 Enter fallback 受 ChatGPT 当前输入控件行为影响。

### GPT 回复超时
确认 ChatGPT 是否仍在生成、是否弹出网络错误/验证提示。检查 `isGenerating()` 和 assistant 节点选择器。不要仅凭文本出现就判定完成。

### ADB reverse 不可用
确认当前雷电实例对应的 ADB serial 和 ADB 版本。尝试使用雷电安装目录自带 adb。若该版本不支持 reverse，交由 Windows Bridge 开发者设计隔离的替代网络方案，不要直接开放 0.0.0.0。

## 隐私

该脚本只向 ChatGPT 网页输入用户通过 Bridge 下发的任务，并将页面中最后一条 assistant 回复回传。它不应扫描其他标签页、读取浏览历史或访问登录凭据。
